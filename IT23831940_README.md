# IT23831940 - Singlish Transliteration Accuracy Testing

## 📌 Project Overview

This project automates testing of the Singlish to Sinhala transliteration feature available at:
https://www.pixelssuite.com/chat-translator

The system uses Python and Playwright to automatically input test cases, capture outputs, and evaluate the accuracy by comparing expected and actual results.

## 📦 Installation

### Step 1 - Install Dependencies

Open Command Prompt and run:

```bash
python -m pip install -U pip
python -m pip install playwright openpyxl
python -m playwright install
```

---

## ▶️ How to Run the Project

### Step 1 - Prepare Test Cases

Open the Excel file:

```
IT23831940_Test_cases.xlsx
```

Fill ONLY these columns:

* Test Case ID
* Input length type (S / M / L)
* Input
* Expected output

❗ Do NOT fill:

* Actual output
* Status

---

### Step 2 - Close Excel File

Make sure the Excel file is closed before running the script.

---

### Step 3 - Run the Automation Script

Run the following command:

```bash
python IT23831940_test_automation.py --excel "IT23831940_Test_cases.xlsx" --url "https://www.pixelssuite.com/chat-translator" --wait-ms 5000 --slow-mo-ms 200
```

👉 If your file is in another location, use full path:

```bash
python IT23831940_test_automation.py --excel "C:\Path\To\Your\IT23831940_Test_cases.xlsx" --url "https://www.pixelssuite.com/chat-translator"
```

---

### Step 4 - View Results

After execution, open the Excel file again.

You will see:

* **Actual Output** → filled automatically
* **Status** → PASS or FAIL

## 📝 Notes

* Input length types:

  * S → Short (≤ 30 characters)
  * M → Medium (31–299 characters)
  * L → Long (300–450 characters)

* Test Case ID format:

  * Negative test cases start with **Neg**
  * Positive test cases start with **Pos**

* This assignment mainly focuses on **negative test cases (FAIL scenarios)**.

* If UI interaction errors (timeouts or delays) occur, re-running the script usually resolves them.
